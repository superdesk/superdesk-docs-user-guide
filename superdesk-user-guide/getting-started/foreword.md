This guide describes Superdesk 3.6 and later versions. It is written for journalists, editors and newsroom administrators.

When a feature was added after Superdesk 2.0, its section starts with a line such as *Available since Superdesk 2.8.* If you use an older version, that feature may be missing or work differently.

Your installation may differ from the examples in this guide. Desks, stages, user roles and optional modules are all configured per newsroom.

New to Superdesk? Start with [What is Superdesk?](what-is-superdesk.md) and then [Logging in and single sign-on](logging-in-and-single-sign-on.md).

For technical documentation for developers and system administrators, see [superdesk.readthedocs.io](https://superdesk.readthedocs.io).

For news about the project, see [www.superdesk.org](https://www.superdesk.org).
