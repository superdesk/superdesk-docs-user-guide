# What is Superdesk?

Superdesk is a newsroom system for producing and distributing news. Journalists and editors use it to take in content from agencies and other sources, write and edit stories, work with pictures and video, and publish the result to websites, apps, partners and other outputs. All of this happens in one application, so the whole newsroom works on the same content.

Many people work in Superdesk at the same time. Work is organised in desks, and each desk has stages that show how far an item has moved through the workflow. User roles decide what each person can do. Desks, stages and roles are all set up for your newsroom.

This manual covers the Superdesk core and its optional modules. Your newsroom may use some of these modules, all of them, or none. If you do not see a module described here, ask your administrator. The optional modules are:

* [Planning](../superdesk-planning-component/README.md): plan events and coverage, and hand out assignments.
* [Broadcasting](../broadcasting-shows-and-rundowns.md): manage shows and build rundowns for radio and TV.
* [Availability management](../availability-management/README.md): track when freelancers are available for work.
* [Asset management](../integrations-and-advanced-features/asset-management.md): store and reuse images, video and other files across items.
* [Content lists](../integrations-and-advanced-features/content-lists.md): curate lists of articles for your websites and apps.
* [AI features](../integrations-and-advanced-features/ai-features.md): suggest headlines, summaries, translations and tags.
* [Analytics](../integrations-and-advanced-features/analytics.md): run reports on your content and newsroom activity.

If a term in this guide is new to you, look it up in the [Superdesk Glossary and Terminology Guide](../reference/superdesk-glossary-and-terminology-guide.md).

## The basics

In Superdesk:

* All users can search and read all content in Superdesk, except for individual Personal Spaces (and deliberately hidden Stages/Desks).
* Users can edit content in Desks they are a member of.
* Users can perform only the actions allowed by their role.
* Desks can be configured with two or more Stages to manage how content flows on the Desk.
* All Desks, all Stages, and all user roles are configurable. (This means that your individual instance of Superdesk might vary from the examples presented in this documentation.)
* The top bar and the main menu have labels for screen readers.
