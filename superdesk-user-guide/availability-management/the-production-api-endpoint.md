# The Production API endpoint

The Availability Manager exposes REST API endpoints for external integrations and programmatic access.

[https://github.com/superdesk/superdesk-core/blob/ce2f1db7927898569910a63af0cac314acd7510d/specs/productionapi.yaml#L4](https://github.com/superdesk/superdesk-core/blob/ce2f1db7927898569910a63af0cac314acd7510d/specs/productionapi.yaml#L4)

#### API Base

* **Base URL**: `/prodapi/` (or as configured in your Superdesk installation)
* **Authentication**: All endpoints require valid authentication
* **Version**: Superdesk Production API 2.0
