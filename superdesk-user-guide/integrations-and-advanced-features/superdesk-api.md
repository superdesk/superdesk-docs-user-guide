# Superdesk API

Superdesk features a **Content API**, and as of Superdesk v1.33 it also provides a new API: the **Superdesk Production API**.

* The Content API allows third-party apps to interact with content that has been published through Superdesk.
* The Production API allows third-party apps to consume content within Superdesk that has yet to be published.

The Production API was introduced to provide access to production (unpublished) content, addressing integration needs identified while working with news organisations.
